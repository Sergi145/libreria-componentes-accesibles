Un conjunto de componentes de UI accesibles, cada uno con su propio HTML, CSS y JavaScript independientes.

El JavaScript añade la interacción de expandir/colapsar y la navegación por teclado; sin él, verás todo el contenido abierto.

Ese es el objetivo de cada componente; revisa el README de cada uno para ver las notas de accesibilidad específicas.

¿Qué es esta librería?

Un conjunto de componentes de UI accesibles, cada uno con su propio HTML, CSS y JavaScript independientes.

¿Necesito JavaScript para usarlo?

No en esta variante: el navegador abre y cierra cada panel.
